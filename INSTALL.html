설치 안내 · Windows · Chrome

Power Link 설치하기

드래그로 링크를 모으고, 여러 크롬 프로필의 최근 화면을 한곳에서 보고 이동하는 크리에이터용 확장

걸리는 시간약 5분
필요한 것Windows 10/11 · Chrome 116+
관리자 권한필요 없음
먼저 알아 두기 — Power Link는 두 부분으로 되어 있어요. ① 크롬 확장(모든 기능)과 ② 도우미(다른 크롬 프로필의 ‘최근 화면’ 연동 전용)예요. 프로필을 하나만 쓴다면 3단계까지만 하면 돼요.

1. 확장 설치 필수

1

압축 파일을 아래 폴더에 풀기

받은 power-link-v버전.zip의 내용을 아래 경로에 그대로 풀어 주세요. manifest.json이 이 폴더 바로 안에 있어야 해요.

C:\GitHub\power-link-extension\dist
경로를 꼭 똑같이 맞추는 걸 권장해요. 확장의 ID가 폴더 경로로 정해지는데, 이 경로면 도우미가 추가 설정 없이 바로 연결돼요. 다른 곳에 풀었다면 5단계의 ‘다른 경로에 풀었을 때’를 따라 주세요.
2

크롬에 확장 올리기

  1. 크롬 주소창에 아래 주소를 입력해요.
    chrome://extensions
  2. 오른쪽 위 개발자 모드를 켜요.
  3. 압축해제된 확장 프로그램을 로드합니다를 누르고 1단계 폴더(dist)를 선택해요.
  4. 툴바의 퍼즐 아이콘에서 Power Link 옆 핀을 눌러 고정해 두면 편해요.
3

잘 되는지 확인

  • 아무 페이지에서 Ctrl + 마우스 오른쪽 버튼 드래그 → 파란 박스 안의 링크가 복사돼요.
  • Shift + 오른쪽 드래그 → 새 탭으로 열기 · Alt + 오른쪽 드래그(자유도형) → 목록에 저장
  • Alt + Shift + L → 사이드바 열기
유튜브 조회수·구독자 같은 상세 정보는 설정 › YouTube API에 본인 API 키를 넣으면 자동으로 채워져요. (선택)

2. 다른 프로필 연동 여러 크롬 프로필을 쓸 때

4

모든 프로필에 같은 폴더로 설치

크롬 프로필마다 2단계를 반복하되, 같은 dist 폴더를 선택해 주세요. 같은 폴더여야 모든 프로필에서 확장 ID가 같아져서 서로 연결돼요.

5

도우미 설치 (install.bat)

아래 파일을 더블클릭해요. 창에 [OK] Power Link bridge helper installed.가 보이면 끝이에요.

C:\GitHub\power-link-extension\dist\native-host\install.bat

다른 경로에 풀었을 때 — chrome://extensions의 Power Link 카드에 보이는 ID(영문 32자)를 복사한 뒤, native-host 폴더에서 명령 프롬프트를 열고 이렇게 실행해요.

install.bat 여기에_확장ID
‘Windows의 PC 보호’ 창이 뜨면 추가 정보 → 실행을 눌러 주세요. 도우미는 현재 사용자 영역에만 설치되고, 탭 제목·주소 목록을 이 PC 안(%LOCALAPPDATA%\PowerLink)에서만 주고받아요. 외부로 보내는 데이터는 없어요.
6

크롬 다시 시작 · 프로필 이름 정하기

  1. 크롬을 완전히 종료했다가 다시 켜요. (또는 사이드바 최근 화면 탭 위의 [다시 연결])
  2. 프로필마다 설정 › 일반 › 이 프로필 이름에 알아보기 쉬운 이름을 넣어요. 예: 업무용, 유튜브
  3. 사이드바 최근 화면에 다른 프로필의 탭이 이름 배지와 함께 보이면 성공이에요. 항목을 누르면 그 프로필 창의 탭으로 이동하고, 닫힌 화면은 다시 열어요.

무엇이 되나요

기능확장만확장 + 도우미
드래그로 링크 복사 · 새 탭 · 저장가능가능
사이드바 수집 링크 · 키워드 · 워치리스트 · 썸네일 zip · 엑셀가능가능
최근 화면 (같은 프로필)가능가능
최근 화면에 다른 프로필 탭 표시 · 이동 · 삭제—가능

자주 묻는 질문

다른 프로필 탭이 안 보여요

① 모든 프로필이 같은 dist 폴더로 설치됐는지, ② install.bat에 넣은 ID가 chrome://extensions의 ID와 같은지 확인하고, ③ 크롬을 완전히 껐다 켜 주세요. 상대 프로필 창이 열려 있어야 ‘온라인’으로 표시돼요.

다른 프로필 항목을 눌렀는데 지금 창에서 열려요

그 프로필의 크롬 창이 닫혀 있으면(오프라인) 이동할 수 없어서, 현재 프로필에서 새 탭으로 열어 드려요.

드래그할 때 빨간 선이 같이 그려져요

다른 마우스 제스처 확장(예: 황금비서, Grabbit)이 오른쪽 드래그에 반응하는 거예요. 그 확장을 끄거나 제스처 기능을 꺼 주세요.

“개발자 모드 확장 사용 중지” 알림이 떠요

압축해제 방식으로 설치한 확장에 크롬이 보여주는 안내예요. 닫기를 눌러도 Power Link는 계속 동작해요.

업데이트는 어떻게 하나요

새 zip을 같은 dist 폴더에 덮어쓴 뒤 chrome://extensions에서 Power Link의 새로고침(↻)을 눌러요. 수집한 링크와 설정은 그대로 유지돼요. 도우미가 바뀐 버전이면 install.bat을 한 번 더 실행해요.

지우고 싶어요

native-host\uninstall.bat으로 도우미를 제거하고, 각 프로필의 chrome://extensions에서 Power Link를 삭제하면 끝이에요.
